로컬 저장소

차트 설정, 전략, 메모, 판단 일지는 해당 브라우저의 localStorage에만 저장돼. 다른 기기로 자동 동기화되지 않으며 브라우저 데이터를 삭제하면 사라질 수 있어.

출처 및 기술적 제약

TradingView 위젯은 외부에서 공급하는 차트이며 사이트에서 위젯 내부 사용자 작도·실시간 데이터에 접근하는 기능을 제공하지 않아. 과거 BTC 가격은 Blockchain.com 공개 API, 대체 데이터는 CSV, 공포·탐욕은 Alternative.me, 펀딩비·OI는 Binance 공개 USDⓈ-M API를 요청해. 일부 지역이나 브라우저에서는 요청이 차단될 수 있어.

미연결 온체인(MVRV, SOPR), 청산 규모, 글로벌 유동성 등은 수치를 만들지 않고 별도 연결이 필요하다고 표시해. 분석 결과에 투자 수익이 보장되지 않아.

실시간 수집 상태 및 데이터 품질

API 요청 성공과 데이터가 최신인지는 별개의 문제야. 마지막 성공 시각과 관측 날짜를 구분해 표시해.

출처상태최근 조회 결과비고
브라우저는 탭이 닫히거나 백그라운드로 전환되면 갱신이 중단·지연될 수 있어. ETF·기관 보유량의 완전 자동 수집은 별도 백엔드 또는 계약된 데이터 API가 필요하며, 이전 스냅샷을 현재 값처럼 표시하지 않아.
